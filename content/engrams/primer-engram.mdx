# Engram #001
El desacoplamiento entre infraestructura y aplicación nos permite escalar sin miedo a las breaking changes del framework.
Visitá http://localhost:3000/engrams/primer-engram y fijate si levanta.

## Prueba de Shiki con Rust

```rust
#[derive(Debug)]
pub struct Engine<T> {
    pub strategy: T,
}

impl<T> Engine<T>
where
    T: Strategy + Send + Sync + 'static,
{
    pub async fn run(&self) -> Result<(), Error> {
        self.strategy.execute().await
    }
}
```
